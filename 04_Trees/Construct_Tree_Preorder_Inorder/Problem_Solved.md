# Tree Problems Solved

| Problem | Topic | Difficulty | Status |
|---|---|---|---|
| LeetCode 105 | Construct Binary Tree from Preorder and Inorder Traversal | Medium | Accepted |

## Key Learnings

- Preorder identifies the root.
- Inorder separates the left and right subtrees.
- The left subtree size determines the preorder split.
- Recursion constructs each subtree.
- Both traversals together uniquely identify the tree when all values are distinct.
