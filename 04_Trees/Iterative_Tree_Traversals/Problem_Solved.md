# Day 7 — Iterative Tree Traversals

## Problems Practiced

### 1. LeetCode 144 — Binary Tree Preorder Traversal
- **Traversal:** Root → Left → Right
- **Approach:** Stack
- **Time Complexity:** O(n)
- **Auxiliary Space:** O(n)

### 2. LeetCode 94 — Binary Tree Inorder Traversal
- **Traversal:** Left → Root → Right
- **Approach:** Stack and a current-node pointer
- **Time Complexity:** O(n)
- **Auxiliary Space:** O(n)

### 3. LeetCode 145 — Binary Tree Postorder Traversal
- **Traversal:** Left → Right → Root
- **Approach:** Stack and deque
- **Time Complexity:** O(n)
- **Auxiliary Space:** O(n)

## Key Learnings

- Implementing tree traversals without recursion.
- Understanding stack behavior and child ordering.
- Using a deque to build postorder output efficiently.
- Handling empty trees.
