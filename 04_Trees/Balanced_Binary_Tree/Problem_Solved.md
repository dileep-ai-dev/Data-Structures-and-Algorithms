# Problem Solved — Balanced Binary Tree

- **LeetCode Number:** 110
- **Problem:** Balanced Binary Tree
- **Difficulty:** Easy
- **Link:** https://leetcode.com/problems/balanced-binary-tree/
- **Status:** Solved

## Approach
Use recursive height calculation. Return `-1` if a subtree is unbalanced; otherwise, return its height.

## Complexity
- **Time:** O(n)
- **Auxiliary Space:** O(h)

## Key Learning
A sentinel value can indicate an invalid subtree and allow the algorithm to stop unnecessary work.
