# Tree Problems Solved

| Problem | Topic | Difficulty | Status |
|---|---|---|---|
| LeetCode 236 | Lowest Common Ancestor of a Binary Tree | Medium | Accepted |

## Key Learning
- An ancestor is a node on the path from the root to a target node.
- The LCA is the lowest common ancestor shared by both target nodes.
- Recursion checks both left and right subtrees.
- If both sides return a node, the current node is the LCA.
